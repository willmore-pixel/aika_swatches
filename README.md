# Aika 色卡 Swatches

這裡放工作室網站的色卡照片。

- **新增色卡**：打開 `leather`（皮革）或 `canvas`（布樣）資料夾，按「Add file → Upload files」上傳照片，再按「Commit changes」。
- **檔名就是客人看到的名稱**，例如 `焦糖 Caramel.jpg`。上傳前可以先改好檔名。
- **刪除色卡**：點開照片，按右上角「⋯ → Delete file」。
- 上傳或刪除後約 1–2 分鐘，網站 https://willmore-pixel.github.io/aika_shoes_studio/ 會自動更新。照片會自動裁成正方形。

## 鞋款 Styles

- 在上架頁 https://willmore-pixel.github.io/aika_swatches/upload/#styles 的「鞋款」分頁上傳線稿（PDF 或 SVG）。可以換色的部位要塗上鮮豔的顏色，一種顏色就是一個部位。
- 每個鞋款存成 `styles/<id>.json`；`styles/order.json` 是網站上的順序。上架頁可以調整順序和刪除，不用動這些檔案。
